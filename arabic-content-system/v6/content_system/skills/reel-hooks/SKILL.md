# Hooks

Read `content_system/guides/hooks.md`.
- Write the payoff first. The hook may imply only what the script delivers.
- At least 4 candidates from at least 3 types (scene, number, paradox, contradiction, demonstration, comparison, delayed reveal, story cold open). Rewordings of the same idea count as one.
- Score each 1–5 on clarity, specificity, relevance, curiosity, credibility, originality (J), speakability, payoff. Any 1 on credibility or payoff disqualifies it.
- **Stories:** the hook sets up the question and holds back the turn. Don't put the whole setup in the opening (v3 EP02's mistake).
- **Batch check:** no two hooks in a batch open the same way. At most 2 approved reels open with a question.
- Keep the runner-up as `[ALT]` when an A/B test is possible.
