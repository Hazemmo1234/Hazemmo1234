# Science and accuracy protocol (stage 7)

## 1. Build a claim ledger

List every factual claim in the draft, spoken or on screen. Give each one a label:

| Label | Meaning | How it may be said |
|---|---|---|
| **VERIFIED** | Checked against the primary source (abstract at minimum) in this session | Plainly, with the study context ("في تجربة على…") |
| **MECHANISM-PLAUSIBLE** | Supported by a mechanistic/biomechanical study but not proven to cause the outcome | "غالبًا"، "من أخطر اللحظات". Never "السبب هو" |
| **PRINCIPLE** | Established training/rehab principle (progressive overload, specificity) without one specific trial behind the wording | As coaching logic, not "الدراسات أثبتت" |
| **CARRIED** | A non-scientific fact (sports history) taken from the research file with its sources, not re-verified this session | Only as stated in the sources. Keep its «ممنوع يتقال» list |
| **OPINION/CREATIVE** | Framing, metaphor, analogy | Shouldn't read as data |
| **UNSUPPORTED** | Can't be supported | Cut it, or rewrite until it can be supported |

## 2. Verify

- Use PubMed (MCP `PubMed search_articles` / `get_article_metadata`) or the journal page.
  Read at least the abstract. Check n, population, comparison, outcome, follow-up.
- Never cite from memory alone. Never fabricate a DOI, a number or a quote.
- If a source can't be reached, mark the claim as unverified and say so in the report.

## 3. Translate numbers honestly

- **Relative vs absolute:** "33% → 22%" (absolute) is clearer and more honest than "35% less
  risk" (relative). Prefer absolute when both exist.
- **Say what was compared.** "programmes *including* the Nordic", not "the Nordic halves injuries".
- **Sample size on screen** when n is small (< 50). Say it out loud only if it changes the meaning.
- **Population:** don't move a result from elite athletes to everyone without a qualifier.

## 4. Red-flag language

- Pain: don't imply that pain = damage, or that pain must be ignored. "الوجع معلومة."
- Imaging: no scary imaging language.
- Posture and injury: no "this posture will destroy your back".
- Absolutes: "مالوش أي فايدة"، "دايمًا"، "أبدًا". Replace with the actual condition.
- Self-tests: say what a self-test measures and what it doesn't.

## 5. Escalate

If the draft's hook depends on an UNSUPPORTED claim, the hook changes, not the evidence.
