# Reel brief: input template

Copy this file to `briefs/<id>.md`, fill what you know, and leave the rest blank (the
system will ask for what is missing only if it changes the script).

```markdown
---
id:                     # e.g. A4, EP6 (stable; never reuse)
series:                 # approved | story | maloosh | new
target_seconds:         # e.g. 35-45 (series «مالوش لازمة»: ≤25)
format:                 # talking head / voice-over + motion graphics / demo at the wall / story cards
---
## الموضوع
(one line: the topic)

## المشاهد المستهدف
(a situation, not a demographic: «حد رجع يلعب بعد التواء كاحل ولسه بيحس إنه مش واثق»)

## الفكرة الأساسية في جملة
(optional. If empty, the system proposes 2–3)

## الادعاءات العلمية المهمة + مصادرها
- claim — source (author year journal / link) — what you're sure of / not sure of

## اللي لازم يتقال / اللي ممنوع يتقال
- لازم:
- ممنوع:

## قيود إبداعية
(visuals available, location, props, things you won't say on camera, CTA preference: save / comment keyword / DM «START» / none)

## الهدف من الريل
(reach / saves / DMs / authority on a topic / series continuity)

## سطور عاجباك ولازم تفضل
(lines from earlier drafts to protect)

## عينات صوت (optional but valuable)
(paste 1–3 transcripts of you speaking naturally. They calibrate the voice guide)

## ملاحظات
```
