# Round 1 → v4: pipeline worknotes (stages 1–11, per script)

Hook scoring uses `system/HOOK_ENGINEERING.md`: 8 criteria × 1–5 = 40 max. C = clarity,
S = specificity, R = relevance, Cu = curiosity, Cr = credibility, O = originality
(judgement), Sp = speakability, P = payoff alignment. Claim labels follow
`system/SCIENCE_PROTOCOL.md`. Pass history: pass 1 → lint/rubric → pass 2 (compression,
spoken edit, hook-pattern fix) → targeted pass on the weakest.
