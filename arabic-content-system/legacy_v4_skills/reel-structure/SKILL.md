# Narrative architecture and middle hooks (stages 4–5)

Read `system/NARRATIVE_STRUCTURES.md` and `system/MIDDLE_HOOKS.md`.

1. **Choose a structure** that fits this topic. Write why. Within one batch, avoid using
   the same structure for more than half the scripts.
2. **Write a beat list** with estimated seconds per beat (≈1.95 spoken words/second,
   calibrated in `tools/calibration.json`). Each beat gets one job: hook, setup, mechanism,
   proof, demo, turn, payoff, action.
3. **Place the middle hook** where the first gap closes. Use a move from MIDDLE_HOOKS
   (escalating number, answer→new question, demo, story turn, callback, stakes,
   prediction→data). It must be true and come out of the content.
4. **Map promises:** list each implicit question the hook and middle raise, and the beat
   that answers it. Any unanswered promise means a structural fix.
5. **Place caveats:** decide which caveats are spoken (≤1 short clause) and which go on
   screen.
