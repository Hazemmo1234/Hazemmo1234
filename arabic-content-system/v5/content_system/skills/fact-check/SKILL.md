# Fact check

Follow `content_system/guides/fact_check_protocol.md`.
1. Build the claim ledger: claim | label | source | what the source says | verdict.
2. Science: PubMed tools or full text. Sports: official records or reference compilations plus a contemporary match report.
3. Resize overstatements; don't bolt on long disclaimers.
4. Conflicting sources: use a range, and note it.
5. Re-check the *final* wording, because compression often changes claims (EP01 v5 lost "when" the 40 days were said, and it was restored).
6. Report what was verified, what was carried, and what couldn't be checked. Never fabricate.
