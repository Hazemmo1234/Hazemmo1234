# Content system v5: project instructions

Writes Egyptian-Arabic short-form scripts for @hazemmohamed.rehab. Scripts only.

- For any script request, use `reel-pipeline`. It routes stories to `afcon-storytelling` and explainers or series to `fitness-rehab-scripts`.
- Deliver finished scripts in files. Analysis serves the rewrite. Don't stop at a plan or an audit.
- Choose the intervention level per script (targeted / structural / reconstruction). Keep a strong line only if it's still the best line in the new structure.
- Never invent dialogue, feelings, motives, scenes, studies, numbers, minutes or analytics. Verify with `fact-check`.
- Before saying a script is done: lint 0 FAIL, regression passing, checklist applied to the file, rubric scored, change from the source measured.
- Rubric scores are diagnostics, never predictions.
- Don't modify `/home/user/reel-studio`, `/home/user/remotion`, global settings, or `../source/`.
